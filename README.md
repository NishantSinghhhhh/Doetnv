# Doetnv
It's a Web3 advertising infrastructure platform that enables decentralized ad management with on-chain USDC payments, IPFS storage, and dynamic bidding mechanisms.
Key highlights:
📦 Publisher SDK - Enables easy integration of decentralized ads on any website:

Simple 3-step setup with npm install ad402-sdk
Ad402Provider for configuration
Ad402Slot components for placing ads
Supports banner, square, mobile, and sidebar ad formats

💰 Settlement - USDC payments via EIP-3009 on Polygon network
🌐 Storage - All ad content hosted on IPFS/Lighthouse for permanence
⚡ Auction System - Dynamic bidding for occupied slots, instant acquisition for open inventory
🏗️ Architecture - Built with Next.js/TypeScript, includes SDK, main platform, and payment facilitator
Platform Links:

Live: https://ad402.io
NPM: https://www.npmjs.com/package/ad402-sdk

The SDK allows publishers to monetize their sites in just a few lines of code, while advertisers can purchase ad slots directly with USDC in a trustless, decentralized manner.
